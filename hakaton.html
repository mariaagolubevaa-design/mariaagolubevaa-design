О проекте

НРООИ «Инватур» – некоммерческая организация, которая помогает людям с инвалидностью: защищает их права, поддерживает социальную интеграцию и занимается реабилитацией

Чтобы получить помощь, пользователям нужно заполнять различные формы. Сейчас этот процесс вызывает сложности

Стандартная Яндекс форма (01)
пользователь с обычным зрением слабовидящий пользователь

Проблема

Слабовидящим и незрячим пользователям сложно самостоятельно заполнять
стандартные Я. Формы. Скринридер последовательно озвучивает вопросы
и варианты ответа, из-за чего элементы сливаются в один поток.
Пользователю сложно понять структуру формы и найти нужный чекбокс.

Цель

Сделать анкетирование доступным для слабовидящих и незрячих пользователей с учётом принципов A11y

Задача

Спроектировать чат-бота для проведения анкетирования

Ограничения

(01) Стандартные ограничения по A11Y
(02) Вопрос должен быть один на странице и озвучиваться
(03) Реализация должна была быть через чат-бот в тг
