Решения и дизайн

Контекст

Нашей целью было спроектировать геймифицированный флоу
в уже имеющееся приложение умного дома. По итогам исследования,
мы пришли к выводу, что квартирный вопрос стоит довольно остро в обществе
и дом внутри приложения умного дома может стать своего рода «картой
желаний»

и устройствах в экосистеме

Геймификационный флоу: за выполнение заданий по экосистеме умного дома
пользователь получает заряды (баллы по сложности задания), которые
обменивает на мебель, комнаты и прокачку дома. Чтобы вовлечь
пользователей в приложение и экосистему устройств через понятные сценарии
использования

комфортолюб

/2

не хватает подсказок для устройств

Подсказки по устройствам: рассказываем о пользе устройства и сценариях,
которые с ним можно настроить, с возможностью сразу их применить.
В разделе «Кстати» показываем, как расширить возможности уже имеющихся устройств, чтобы пользователь не тратил время на самостоятельное разбирательство с устройствами и быстрее находил полезные сценарии.

Семейный доступ: члены семьи могут давать друг другу задания (например,

задач и разными уровнями доступа

комбинатор

/4

не хочется разбираться в УУ

Автоматическое добавление готовых сценариев на основе уже имеющихся у пользователя устройств без необходимости настраивать их вручную, чтобы упростить процесс использования умных устройств и снизить порог входа для тех, кто не хочет в них разбираться

комфортолюб

/5

нет ощущения прогресса

За баллы, которые пользователь получает за ежедневные заходы в приложение или выполнение заданий, можно развивать дом: улучшать мебель, добавлять комнаты, где живёт аватар, чтобы дать пользователю наглядный и постоянно растущий результат его активности. Дом становится видимым отражением прогресса

комбинатор

/6

хочется большей персональности

Кастомизация дома: покупка предметов мебели, интеграция с каталогом товаров из Мегамаркет. Оставить покупки можно внутри виртуального дома, чтобы дать пользователю ощущение прогресса и личной вовлечённости, т.к. дом становится результатом его действий в экосистеме

комбинатор

Результат

В итоге, приложение умного дома становится не просто приложением
для подключения новых устройств, а карманным помощником по дому, который
помогает визуализировать даже самые смелые мечты о доме, в котором можно
в игровой форме узнавать об экосистеме, давать задания по дому детям
и устанавливать себе напоминания
